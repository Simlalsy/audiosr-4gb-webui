# AudioSR 低显存版 v1.1.0

基于上游 **AudioSR**（MIT，[haoheliu/versatile_audio_super_resolution](https://github.com/haoheliu/versatile_audio_super_resolution)）的社区修改版：**4 GB 显存笔记本显卡也能跑**，附带本地网页界面（含局域网访问）与 Windows 双击脚本。

## 相比 v1.0.0 的改进

- **启动脚本会自动找 Python 环境**：优先用自带的 `.venv`，其次用系统 Python（需已装依赖）；两者都不可用时给出中文三步指引，不再出现 “系统找不到指定的路径”。
- 新增 **`安装依赖.cmd`**：一键创建 `.venv` 并安装 `requirements.txt`（联网一次，国内走清华 PyPI 镜像）。
- **模型可分卷分发**：完全离线版现在自带模型分卷（4 个 `pytorch_model.bin.part-0x`，单个 < 2 GiB 是 GitHub 的硬限制），首次启动会**自动合并并校验 SHA-256**，之后不再重复。
- 命令行 `run_audiosr.cmd` 的退出码现已正确传递（便于 CI/批处理判断成败）。

## 两个包怎么选

| 包                 | 适用场景                              | 与另一个包的差异                                                                                   |
| ------------------ | ------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **A-自动下载模型** | 有网络、图省事                        | 首次运行自动从 Hugging Face 镜像下载权重（约 5.75 GB）；**若目录里已有完整模型或分卷，则不会下载** |
| **B-完全离线**     | 内网 / 离线机器，或想自己管理权重文件 | 启动脚本内置 `AUDIOSR_OFFLINE=1`：**绝不联网下载模型**；权重缺失时立刻报错并提示放置位置           |

两个包的文件名与解压后的目录：

- `AudioSR-LowVRAM-v1.1.0-A-online-model-download.zip` → 解压得到 `AudioSR-LowVRAM-v1.1.0-A-自动下载模型\`
- `AudioSR-LowVRAM-v1.1.0-B-fully-offline.zip` → 解压得到 `AudioSR-LowVRAM-v1.1.0-B-完全离线\`

用法一样（双击 `双击启动网页界面.cmd`），压缩包内各带一份 `使用说明.txt`。

## 快速开始

**A 版（自动下载）**

1. 双击 `安装依赖.cmd`（联网一次，创建 `.venv`）
2. 双击 `双击启动网页界面.cmd` → 浏览器打开 <http://127.0.0.1:7860>

**B 版（完全离线）**

1. 把 4 个模型分卷（本页附件）下载后**放到解压出来的目录里**（与 `.cmd` 同级）
2. 双击 `安装依赖.cmd`（联网一次，创建 `.venv`；完全无网时可在有网机器上装好后整体拷贝）
3. 双击 `双击启动网页界面.cmd` → 首次启动自动合并分卷并校验（约 1~2 分钟），之后立即可用

手机 / 同网电脑：使用 `双击启动局域网网页界面.cmd`，窗口会打印 `http://<本机IP>:7860`。
命令行：`run_audiosr.cmd -i "D:\audio\song.mp3" --chunking --out_format mp3`。

## 模型分卷（B 版必看，A 版可选）

- 把分卷放在**程序目录**（与 `双击启动网页界面.cmd` 同一层），首次启动自动合并成 `pytorch_model.bin`。
- 合并后会校验整文件 SHA-256（见下），校验不过会报错并提示重新下载。
- 也支持直接放完整的 `pytorch_model.bin`（放程序目录、`models\` 子目录，或用环境变量 `AUDIOSR_CKPT` 指定）。

## 环境要求

- Windows 10/11 + Python 3.10 左右（实测 3.10.1 + torch 2.0.1+cu118 / torchaudio 2.0.2+cu118）
- NVIDIA 显卡 4 GB 显存起（实测 RTX 3050 Laptop 4 GB）；也可 `--device cpu`（很慢）
- **ffmpeg 与 ffprobe 必须在 PATH**（保存输出时会调用；`winget install Gyan.FFmpeg`）

## 实测性能（RTX 3050 Laptop 4 GB，10.24 秒单声道输入，50 步 DDIM）

| 配置                                   | 峰值显存 | 端到端耗时 |
| -------------------------------------- | -------- | ---------- |
| 默认（VAE / 声码器在 CPU）             | 0.63 GiB | 51.0 s     |
| `--gpu_vae`（VAE / 声码器上显卡 fp16） | 2.93 GiB | 19.2 s     |
