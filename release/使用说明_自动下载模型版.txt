============================================================
 AudioSR 低显存版 —— A 版：自动下载模型（需要联网）
============================================================

【这个包是做什么的】
  AudioSR 是"音频超分辨率"（把低音质音频变高清）模型。
  本包是它的社区修改版：让 4 GB 显存的笔记本显卡也能跑，并附带
  网页界面（含局域网访问）、双击即用脚本。算法与模型代码来自上游，
  未作修改，只增加了外围工具。

【第一次使用：三步】
  1) 安装 Python 依赖（只需一次，需要联网）
       双击  安装依赖.cmd   （自动创建 .venv 并安装 requirements.txt）
     说明：安装**不需要访问 GitHub**（上游那条 git+diffusers 依赖本项目并未用到，已注释）。
     若不想用它，也可手动执行：
           python -m venv .venv
           .venv\Scripts\pip install -r requirements.txt

  2) 双击：双击启动网页界面.cmd
     首次启动会自动从 Hugging Face 镜像下载模型权重
     （pytorch_model.bin，约 5.75 GB），下载到：
         本程序目录\models\          ← 不会占用 C 盘
     下载期间进度条会停在 "Loading AudioSR: basic"，属正常现象
     （页面也会提示“正在下载模型权重”，失败会直接显示原因）。
     国内网络已默认使用 https://hf-mirror.com 镜像，失败会自动再试官方站。
     ★ 如果程序目录里已经有完整 pytorch_model.bin，或放了
       pytorch_model.bin.part-01… 分卷（见 Releases 页面），则不会下载：
       分卷会在首次启动时自动合并并校验 SHA-256。

  3) 浏览器自动打开 http://127.0.0.1:7860
     拖入音频 → 点"开始处理" → 完成后可试听 / 下载。
     手机、平板等同一 Wi-Fi 设备请改用：双击启动局域网网页界面.cmd
     （窗口会打印 http://<本机IP>:7860 的访问地址）
     若提示找不到 Python 环境，窗口会给出三种解决办法。

【其它启动方式】
  · 双击选择音频处理.cmd    弹窗选文件 → 默认参数处理 → 自动打开输出目录
  · run_audiosr.cmd -i "文件路径" [参数]
       例：run_audiosr.cmd -i "D:\audio\song.mp3" --chunking --out_format mp3

【v1.1.5 新增：进度 / 强制停止 / 可选处理】
  · 网页界面有实时进度条（百分比 + 当前阶段 + 预计剩余时间），处理中可随时点
    "■ 强制停止"打断任务：不写出结果文件，模型保持常驻，可立刻开始下一个。
  · 网页界面新增几组可选开关（**默认全部关闭，不开时输出与之前完全一致**）：
        高频空气感（合成）   让 96/192 kHz 导出的 24 kHz 以上"有东西"
                            注意：是合成谐波，不是还原出来的细节
        输入带宽 / 多频段融合  来自 AudioSR-Colab-Fork，低频保留得更真实
        响度匹配（LUFS）     分块时逐块对齐音量，消除块与块之间的音量跳变
  · 命令行同名参数：--synthetic_air / --input_cutoff / --multiband_ensemble /
    --loudness_match（详见包内 README.md 第 7 节）。
  · 另修复了高采样率导出的重采样质量问题（原来 21 kHz 会在 27 kHz 留下 -15 dB
    镜像，现在约 -130 dB），8–48 kHz 的原始内容不受影响。

【前置要求】
  · Windows 10/11 + Python 3.9/3.10/3.11（推荐 3.10）
      注意：PyTorch 2.0.1+cu118 没有 3.12+ 的安装包，
      用 3.12/3.13/3.15 会报 torch==2.0.1+cu118 找不到。
      已装过 3.10/3.11 但不在默认位置时，先执行：
          set AUDIOSR_PY_BASE=D:\Python310\python.exe
  · ffmpeg 与 ffprobe 必须在 PATH 中（保存输出时会调用）
       安装：winget install Gyan.FFmpeg
  · NVIDIA 显卡 4 GB 显存即可；纯 CPU 也行（--device cpu，很慢）

【输出位置】
  output\<时间戳>\<文件名>_AudioSR_Processed_48K.wav
  加 --out_format mp3|flac|m4a|ogg 会另存一份，wav 母带保留。

【想完全离线？（可选）】
  程序内置离线模式：把 pytorch_model.bin 放到本目录（或 models\ 子目录，
  或用环境变量 AUDIOSR_CKPT 指定），并在启动脚本里加一行：
      set AUDIOSR_OFFLINE=1
  这样运行期间绝不会联网；找不到权重时会直接报错并提示放置位置。
