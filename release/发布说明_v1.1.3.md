# AudioSR 低显存版 v1.1.3

基于上游 **AudioSR**（MIT，[haoheliu/versatile_audio_super_resolution](https://github.com/haoheliu/versatile_audio_super_resolution)）的社区修改版：**4 GB 显存笔记本显卡也能跑**，附带本地网页界面（含局域网访问）与 Windows 双击脚本。

> 首次运行会自动下载模型权重（约 5.75 GB，缓存到用户目录，之后不再下载）。想完全离线运行的做法见文末。

## v1.1.3 改进

- **网页状态提示更准确**，不再“看起来卡住”：
  - 程序目录里**没有**权重时显示：`首次运行：正在下载模型权重（约 5.75 GB，进度见程序窗口）…`
  - 已有本地权重、正在加载时显示：`模型加载中（首次约 1 分钟，硬盘较慢时更久）…`
  - **加载失败时直接显示原因**（红色），不再无限转圈。
- 健康接口新增 `local_ckpt` / `model_error` 字段，便于脚本化判断。

## v1.1.2 修复

- **安装依赖不再需要访问 GitHub**：上游 `requirements.txt` 第 2 行的
  `git+https://github.com/huggingface/diffusers.git` 已注释（本项目没有任何代码 import diffusers），
  避免 pip 从 GitHub 克隆失败（`Recv failure: Connection was reset`）导致整个安装中断。

## v1.1.1 修复

- **只接受 Python 3.9 / 3.10 / 3.11**（优先 `py -3.10`），避免抓到 3.12+ 报
  `Could not find a version that satisfies the requirement torch==2.0.1+cu118`；
  找不到兼容解释器时打印中文指引（`AUDIOSR_PY_BASE` 可指定）。

## 快速开始（三步）

1. 解压 `AudioSR-LowVRAM-v1.1.3-A-online-model-download.zip` → 得到 `AudioSR-LowVRAM-v1.1.3-A-自动下载模型\`
2. 双击 **`安装依赖.cmd`**（联网一次，创建 `.venv`，PyTorch 约 2.5 GB）
3. 双击 **`双击启动网页界面.cmd`** → 浏览器自动打开 <http://127.0.0.1:7860>

首次启动会自动从 Hugging Face 镜像下载模型权重（页面与程序窗口都会提示进度）；下载完成后拖入音频 → “开始处理” → 试听/下载。

- 手机 / 同网电脑：使用 `双击启动局域网网页界面.cmd`，窗口会打印 `http://<本机IP>:7860`
- 命令行：`run_audiosr.cmd -i "D:\audio\song.mp3" --chunking --out_format mp3`
- 选文件即处理：`双击选择音频处理.cmd`

## 已经有模型文件？（跳过下载）

把 `pytorch_model.bin`（约 5.75 GB）放到**程序目录**即可，程序会直接使用、不再下载：

```bat
:: 同一磁盘可用硬链接，瞬间完成且不占额外空间
mklink /H "程序目录\pytorch_model.bin" "E:\XIAOMI\dts\pytorch_model.bin"
```

也可以放到 `models\` 子目录，或用环境变量 `AUDIOSR_CKPT` 指定。

## 想完全离线运行？（可选）

在上面基础上，于启动脚本里加一行 `set AUDIOSR_OFFLINE=1` 再启动：此时程序**绝不会联网下载权重**，找不到本地权重会直接报错并提示放置位置。

## 环境要求

- Windows 10/11 + **Python 3.9 / 3.10 / 3.11（推荐 3.10）**——3.12+ 没有 `torch==2.0.1+cu118` 的安装包
- NVIDIA 显卡 4 GB 显存起（实测 RTX 3050 Laptop 4 GB）；也可 `--device cpu`（很慢）
- **ffmpeg 与 ffprobe 必须在 PATH**（保存输出时会调用；`winget install Gyan.FFmpeg`）

## 实测性能（RTX 3050 Laptop 4 GB，10.24 秒单声道输入，50 步 DDIM）

| 配置                                   | 峰值显存 | 端到端耗时 |
| -------------------------------------- | -------- | ---------- |
| 默认（VAE / 声码器在 CPU）             | 0.63 GiB | 51.0 s     |
| `--gpu_vae`（VAE / 声码器上显卡 fp16） | 2.93 GiB | 19.2 s     |
