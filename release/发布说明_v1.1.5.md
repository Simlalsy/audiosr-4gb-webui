# AudioSR 低显存版 v1.1.5

基于上游 **AudioSR**（MIT，[haoheliu/versatile_audio_super_resolution](https://github.com/haoheliu/versatile_audio_super_resolution)）的社区修改版：**4 GB 显存笔记本显卡也能跑**，附带本地网页界面（含局域网访问）与 Windows 双击脚本。

## v1.1.5 改进

### 1. 网页界面：真正的进度条 + 「强制停止」

- 进度不再是估算：改由**推理管线直接上报**（接在 DDIM 采样回调上），显示
  **百分比 + 当前阶段（声道 / 分块 / DDIM 采样步）+ 预计剩余时间**；
  立体声、长音频分块下也**单调递增**，不再每个声道/每块从头跳一遍。
- 新增 **「■ 强制停止」** 按钮（`/api/stop`）：协作式中断，**实测 0.22 秒**内生效，
  不写出结果文件、模型保持常驻，可立刻开始下一个任务；排队中的任务也能单独取消。

### 2. 移植 AudioSR-Colab-Fork 的三项处理（可选，默认关闭）

命令行 `--input_cutoff` / `--multiband_ensemble` / `--loudness_match`，网页界面里对应
「输入带宽」「多频段融合」「响度匹配（LUFS）」三个控件：

- **输入带宽限制**：送入模型的音频重采样到「截止频率 ×2」（而不是低通滤波）；
- **多频段融合**：截止频率以下换回**原始音频**、只保留模型生成的高频（低频更保真）；
- **LUFS 响度匹配**：分块时每块对齐对应输入的感知响度，消除块间音量跳变。

三项**默认全部关闭**，不开时的输出与 v1.1.4 完全一致。

### 3. 可选「高频空气感」：让 96 / 192 kHz 导出不再空白

AudioSR 的内容上限约 **24 kHz**（mel `fmax=24000`，VAE 与声码器都是 48 kHz 模型），
所以 96/192 kHz 导出在 24 kHz 以上本来是一片空白。新增 `--synthetic_air`
（网页「高频空气感」，轻/中/强三档）会取输出的高频八度做平方，把 **24–43 kHz 的二次谐波**
低电平混进去。

> ⚠️ **这是合成内容，不是还原出来的细节**，仅用于让高采样率导出"听起来更通透"。
> 默认关闭；只对 `out_sr > 48000` 生效；带宽受限素材（如 8 kHz 语音）自动跳过。
> 关于"能不能真正解除 48 kHz 上限"的调研结论见 `NOTICE` 与 README 常见问题。

### 4. 重采样质量修复（这是个真 bug）

原先输出重采样与输入带宽限制用的是 `torchaudio.functional.resample`——它的抗镜像
滤波很弱，实测 **21 kHz 音在 48k→96k 后会在 27 kHz 处留下 −15 dB 的镜像**
（导出 96 kHz 时可闻的毛刺），输入下采样还会漏约 −70 dB 混叠。现改用
librosa / soxr：

| 测试点 | 修复前 | 修复后 |
| --- | --- | --- |
| 48k→96k 镜像抑制（21 kHz 测试音） | −15 dB | **−134 dB** |
| 96 kHz 导出 24.5–43 kHz 残余能量 | 5.6e-3 | **2.1e-9** |
| 48k→28k 输入下采样混叠 | −72 dB | **−102 dB** |

8–48 kHz 的**原始内容不受影响**（实测低频段变化 < 0.01%）。

### 5. 依赖

`requirements.txt` 新增两个小包，`安装依赖.cmd` 会自动装好：`pyloudnorm`（LUFS 匹配，
缺失时自动退回峰值匹配）与 `soxr`（高质量重采样后端，缺失时用 librosa 自带滤波器）。

## 之前的修复（v1.1.1 ~ v1.1.4）

- v1.1.4：所有下载都放进程序目录（不占 C 盘）；不再下载 `roberta-base`（约 500 MB）；
  下载失败自动换源；下载成功后自动建立硬链接。
- v1.1.3：网页状态三态显示（下载中 / 加载中 / 失败原因），不再"看起来卡住"。
- v1.1.2：安装依赖不再需要访问 GitHub（注释掉未被使用的 diffusers git 依赖）。
- v1.1.1：只接受 Python 3.9/3.10/3.11（3.12+ 没有 `torch==2.0.1+cu118` 的包）。

## 快速开始（三步）

1. 解压 `AudioSR-LowVRAM-v1.1.5-A-online-model-download.zip` → 得到 `AudioSR-LowVRAM-v1.1.5-A-自动下载模型\`
2. 双击 **`安装依赖.cmd`**（联网一次，创建 `.venv`；缓存全部留在本文件夹）
3. 双击 **`双击启动网页界面.cmd`** → 浏览器自动打开 <http://127.0.0.1:7860>

首次启动会把模型权重（约 5.75 GB）下载到 **`程序目录\models\`**，页面与程序窗口都有提示；完成后即可拖入音频处理。

## 已经有模型文件？（跳过下载）

把 `pytorch_model.bin` 放到**程序目录**即可（同盘可用硬链接，瞬间完成）：

```bat
mklink /H "程序目录\pytorch_model.bin" "D:\某处\pytorch_model.bin"
```

也可放到 `models\` 子目录，或用环境变量 `AUDIOSR_CKPT` 指定。

## 想完全离线运行？（可选）

在上面基础上，于启动脚本里加一行 `set AUDIOSR_OFFLINE=1`：程序**绝不会联网下载权重**，找不到本地权重会直接报错并提示放置位置。

## 环境要求

- Windows 10/11 + **Python 3.9 / 3.10 / 3.11（推荐 3.10）**
- NVIDIA 显卡 4 GB 显存起（实测 RTX 3050 Laptop 4 GB）；也可 `--device cpu`（很慢）
- **ffmpeg 与 ffprobe 必须在 PATH**（保存输出时会调用；`winget install Gyan.FFmpeg`）

## 新增选项一览

| 网页界面 | 命令行 | 默认 | 作用 |
| --- | --- | --- | --- |
| 高频空气感（合成） | `--synthetic_air off/light/medium/strong` | `off` | 合成 24–43 kHz 谐波（需 `--out_sr > 48000`） |
| 输入带宽 | `--input_cutoff <Hz>` | `0`（关） | 按截止频率×2 重采样模型输入（fork v0.5） |
| 多频段融合 | `--multiband_ensemble` | 关 | 截止频率以下保留原始音频（fork v0.3） |
| 响度匹配（LUFS） | `--loudness_match` | 关 | 分块逐块对齐输入响度（fork v0.5） |
| ■ 强制停止 | （网页按钮） | — | 一个采样步内中断，不落盘结果 |

## 实测性能（RTX 3050 Laptop 4 GB，10.24 秒单声道输入，50 步 DDIM）

| 配置                                   | 峰值显存 | 端到端耗时 |
| -------------------------------------- | -------- | ---------- |
| 默认（VAE / 声码器在 CPU）             | 0.63 GiB | 51.0 s     |
| `--gpu_vae`（VAE / 声码器上显卡 fp16） | 2.93 GiB | 19.2 s     |

（上表为默认 48 kHz 输出路径；v1.1.5 的新选项默认关闭，不改变该路径的耗时与显存。）
