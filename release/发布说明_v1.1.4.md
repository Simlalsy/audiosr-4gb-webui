# AudioSR 低显存版 v1.1.4

基于上游 **AudioSR**（MIT，[haoheliu/versatile_audio_super_resolution](https://github.com/haoheliu/versatile_audio_super_resolution)）的社区修改版：**4 GB 显存笔记本显卡也能跑**，附带本地网页界面（含局域网访问）与 Windows 双击脚本。

## v1.1.4 改进（重点：不占 C 盘）

- **所有下载都放进程序文件夹**，不再占用 C 盘：
  - 模型权重与 Hugging Face 缓存 → `程序目录\models\`（`HF_HOME` / `HF_HUB_CACHE` 已指向这里）
  - pip 下载缓存 → `程序目录\.pip-cache\`；pip 临时文件 → `程序目录\.tmp\`
  - 上传/输出本来就在程序目录（`webui_uploads\`、`output\`）
  - 安装完成后可以放心删除 `.pip-cache`、`.tmp` 释放空间（不影响运行）
- **不再需要下载 `roberta-base`（约 500 MB）**：上游 `audiosr/clap/training/data.py` 在**导入时**就加载它，
  而 AudioSR 推理根本用不到 —— 现改为首次使用时才加载（离线环境也能正常启动）。
- **下载失败自动换源**：先试 `hf-mirror.com`，失败再试官方 `huggingface.co`；都失败会给出明确的中文提示与手动下载地址。
- 下载成功后**自动在程序目录建立硬链接** `pytorch_model.bin`（同盘不占额外空间），下次启动直接命中、不再询问网络。

## 之前的修复（v1.1.1 ~ v1.1.3）

- v1.1.3：网页状态三态显示（下载中 / 加载中 / 失败原因），不再“看起来卡住”。
- v1.1.2：安装依赖不再需要访问 GitHub（注释掉未被使用的 diffusers git 依赖）。
- v1.1.1：只接受 Python 3.9/3.10/3.11（3.12+ 没有 `torch==2.0.1+cu118` 的包）。

## 快速开始（三步）

1. 解压 `AudioSR-LowVRAM-v1.1.4-A-online-model-download.zip` → 得到 `AudioSR-LowVRAM-v1.1.4-A-自动下载模型\`
2. 双击 **`安装依赖.cmd`**（联网一次，创建 `.venv`；缓存全部留在本文件夹）
3. 双击 **`双击启动网页界面.cmd`** → 浏览器自动打开 <http://127.0.0.1:7860>

首次启动会把模型权重（约 5.75 GB）下载到 **`程序目录\models\`**，页面与程序窗口都有提示；完成后即可拖入音频处理。

## 已经有模型文件？（跳过下载）

把 `pytorch_model.bin` 放到**程序目录**即可（同盘可用硬链接，瞬间完成）：

```bat
mklink /H "程序目录\pytorch_model.bin" "D:\某处\pytorch_model.bin"
```

也可放到 `models\` 子目录，或用环境变量 `AUDIOSR_CKPT` 指定。

## 想完全离线运行？（可选）

在上面基础上，于启动脚本里加一行 `set AUDIOSR_OFFLINE=1`：程序**绝不会联网下载权重**，找不到本地权重会直接报错并提示放置位置。

## 环境要求

- Windows 10/11 + **Python 3.9 / 3.10 / 3.11（推荐 3.10）**
- NVIDIA 显卡 4 GB 显存起（实测 RTX 3050 Laptop 4 GB）；也可 `--device cpu`（很慢）
- **ffmpeg 与 ffprobe 必须在 PATH**（保存输出时会调用；`winget install Gyan.FFmpeg`）

## 实测性能（RTX 3050 Laptop 4 GB，10.24 秒单声道输入，50 步 DDIM）

| 配置                                   | 峰值显存 | 端到端耗时 |
| -------------------------------------- | -------- | ---------- |
| 默认（VAE / 声码器在 CPU）             | 0.63 GiB | 51.0 s     |
| `--gpu_vae`（VAE / 声码器上显卡 fp16） | 2.93 GiB | 19.2 s     |
