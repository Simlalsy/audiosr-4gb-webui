============================================================
 AudioSR 低显存版 —— B 版：完全离线（不自动下载模型）
============================================================

【和 A 版的唯一区别】
  本版的 4 个启动脚本都内置了 AUDIOSR_OFFLINE=1：
    · 运行期间绝不会联网下载模型权重；
    · 权重缺失时会立刻报错并提示放置位置，不会"偷偷"开始下载。
  其余功能（网页界面、局域网、命令行、输出格式等）与 A 版完全一致。

【第一次使用：三步】
  1) 把模型分卷放到本目录（与 双击启动网页界面.cmd 同一层）
       从 Releases 页面下载这几个分卷（共约 6 GB；单个 < 2 GiB 是 GitHub 的硬限制）：
           pytorch_model.bin.part-01、part-02、part-03、part-04
       全部放到本文件夹根目录。首次启动时会自动合并成 pytorch_model.bin
       并做 SHA-256 校验（约 1~2 分钟，只需一次），之后不再重复。
       ★ 也可以直接放完整的 pytorch_model.bin（约 5.75 GB）：
           放本目录、或 models\ 子目录、或用环境变量 AUDIOSR_CKPT 指定。

  2) 安装 Python 依赖（只需一次）
       双击  安装依赖.cmd   （自动创建 .venv 并安装 requirements.txt）
       这一步需要联网。完全没有网络的机器：先在联网机器上跑完这一步，
       再把整个文件夹（含 .venv）拷过来（.venv 与 Python 安装路径绑定，
       两台机器 Python 版本/路径越一致越稳妥）。

  3) 双击：双击启动网页界面.cmd
     模型已就位，启动后不再有任何下载，直接进入可用状态。
     若提示找不到 Python 环境，窗口会给出三种解决办法。

【其它启动方式】与 A 版相同：
  · 双击启动局域网网页界面.cmd    手机/同网电脑访问
  · 双击选择音频处理.cmd          弹窗选文件处理
  · run_audiosr.cmd -i "文件路径" [参数]

【需要"语音"权重时（可选）】
  默认只用 basic 权重。若要使用 --model_name speech，请另外准备
  haoheliu/audiosr_speech 的 pytorch_model.bin，并用环境变量
  AUDIOSR_CKPT 指向它（例如在启动前的命令行里 set AUDIOSR_CKPT=D:\...）。

【前置要求】
  与 A 版相同：Windows 10/11 + Python 3.10、ffmpeg/ffprobe 在 PATH、
  NVIDIA 显卡 4 GB 显存起（或 --device cpu）。

【输出位置】
  output\<时间戳>\<文件名>_AudioSR_Processed_48K.wav
