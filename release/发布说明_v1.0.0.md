# AudioSR 低显存版 v1.0.0

基于上游 **AudioSR**（MIT，[haoheliu/versatile_audio_super_resolution](https://github.com/haoheliu/versatile_audio_super_resolution)）的社区修改版：**4 GB 显存笔记本显卡也能跑**，并附带本地网页界面（含局域网访问）与 Windows 双击脚本。本页两个发行包**源码完全相同**，只有模型权重的获取方式不同。

## 两个包怎么选

| 包                 | 适用场景                              | 与另一个包的差异                                                                         |
| ------------------ | ------------------------------------- | ---------------------------------------------------------------------------------------- |
| **A-自动下载模型** | 有网络、图省事                        | 首次运行自动从 Hugging Face 镜像下载权重（约 5.75 GB，缓存到用户目录）                   |
| **B-完全离线**     | 内网 / 离线机器，或想自己管理权重文件 | 启动脚本内置 `AUDIOSR_OFFLINE=1`：**绝不联网下载模型**；权重缺失时立刻报错并提示放置位置 |

两个包的文件名与解压后的目录：

- `AudioSR-LowVRAM-v1.0.0-A-online-model-download.zip` → 解压得到 `AudioSR-LowVRAM-v1.0.0-A-自动下载模型\`
- `AudioSR-LowVRAM-v1.0.0-B-fully-offline.zip` → 解压得到 `AudioSR-LowVRAM-v1.0.0-B-完全离线\`

用法一样（双击 `双击启动网页界面.cmd`），压缩包内各带一份 `使用说明.txt`。

## 快速开始（两个包通用）

1. 解压后安装依赖（一次性，需要联网）：
   ```shell
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
2. **A 版**：直接双击 `双击启动网页界面.cmd`，首次自动下载模型；
   **B 版**：先把 `pytorch_model.bin` 放到程序目录（或 `models\`），再双击同一个脚本。
3. 浏览器打开 <http://127.0.0.1:7860>。手机 / 同网电脑请改用 `双击启动局域网网页界面.cmd`，窗口会打印 `http://<本机IP>:7860`。

命令行：`run_audiosr.cmd -i "D:\audio\song.mp3" --chunking --out_format mp3`。

## 环境要求

- Windows 10/11 + Python 3.10 左右（实测 3.10.1 + torch 2.0.1+cu118 / torchaudio 2.0.2+cu118）
- NVIDIA 显卡 4 GB 显存起（实测 RTX 3050 Laptop 4 GB）；也可 `--device cpu`（很慢）
- **ffmpeg 与 ffprobe 必须在 PATH**（保存输出时会调用；`winget install Gyan.FFmpeg`）
- 权重 `pytorch_model.bin` ≈ **5.75 GB**（basic；`--model_name speech` 需另备 speech 权重）

## 实测性能（RTX 3050 Laptop 4 GB，10.24 秒单声道输入，50 步 DDIM）

| 配置                                   | 峰值显存 | 端到端耗时 |
| -------------------------------------- | -------- | ---------- |
| 默认（VAE / 声码器在 CPU）             | 0.63 GiB | 51.0 s     |
| `--gpu_vae`（VAE / 声码器上显卡 fp16） | 2.93 GiB | 19.2 s     |

长音频默认超过 12 秒自动分块（10 秒/块、2 秒交叉淡化）；立体声默认逐声道处理（真立体声，约 2 倍耗时）。

## 功能一览

- 网页界面：拖拽上传 → 队列/进度日志 → 在线试听 → 下载 / 打开输出目录；模型常驻内存只加载一次
- 局域网模式：手机、平板、其它电脑同一 Wi-Fi 直接使用（`--host 0.0.0.0`）
- 输出选项：采样率 8k~192k（内容上限约 24 kHz）、格式 wav/flac/mp3/m4a/ogg、真立体声、长音频分块
- 双击脚本：`双击启动网页界面.cmd`、`双击启动局域网网页界面.cmd`、`双击选择音频处理.cmd`
